description: Create a careful, approval-aware implementation plan for a BOLT feature or production task.
---

Prepare an implementation plan for the user's requested BOLT task.

1. Read project guidance, current stage status, relevant game/technical specifications and Definition of Done.
2. Inspect existing implementation before proposing file changes.
3. Detect the exact Godot version if a Godot project exists.
4. Load router and the smallest relevant skill set; use relevant read-only specialist reviewers when useful.
5. Define objective, in-scope work, explicit out-of-scope work, current state, dependencies, affected files, sequence, risks, tests and acceptance criteria.
6. Identify any approval boundary: canon, scope, architecture, engine, platform, destructive action or release.
7. Save the plan using docs/templates/implementation-plan.md only if the user asked for a saved plan; otherwise return it for review.

Do not implement unless the user explicitly requested implementation. Do not invent project files or approved design facts.
