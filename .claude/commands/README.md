# BOLT · AVENTURA — Claude Code Commands

- `/bolt-continue`: inspect repository state and resume the assigned task.
- `/bolt-handoff`: prepare a factual handoff to the next agent.
- `/bolt-review`: perform a read-only review of the current change.

Commands are workflow prompts, not proof that a task, test, handoff or merge occurred.
