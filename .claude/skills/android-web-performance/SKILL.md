# Android WebView Performance
Read the master prompt. Target low/mid Android around 4 GB RAM and Helio G99-class or weaker. Measure before optimizing: device, OS, WebView, resolution, thermal state, frame-time average/p95/p99, long tasks, memory, decode time and input latency. Budget canvas backing-store memory; DPR multiplies pixel cost. Reduce overdraw, large transparent layers, filters, layout thrashing, repeated parsing and asset decode in hot paths. Cull offscreen entities, batch compatible draws, release world assets and defer noncritical work. Pool only when measured. Test WebView and browser separately. 60 FPS is a measured target, never a guarantee.
