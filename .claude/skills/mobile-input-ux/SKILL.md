# Mobile Input and UX
Read the master prompt. Use Pointer Events and track active pointers by pointerId. Handle pointerup, pointercancel, lostpointercapture, blur, visibilitychange, pause, orientation and scene changes. Support designed multitouch combinations. Register input immediately, not on a later render tick. Prevent stuck buttons. Define accessible touch targets and pressed/disabled states. Apply safe-area insets where relevant. Configure touch-action narrowly. Keep logical actions separate from physical controls. Test simultaneous fingers, rapid taps, held controls, low FPS, browser chrome changes and physical Android devices.
