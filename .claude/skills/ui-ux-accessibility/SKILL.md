# Skill: UI/UX and Accessibility for Mobile Games

For each screen define purpose, primary/secondary actions, navigation graph, back/cancel behavior, focus/selection, loading/error/empty states and persistence. Avoid dead ends and hidden controls.

Design for landscape phones, varied aspect ratios, comfortable touch targets, one/two-handed reach, thumb occlusion and multitouch. Keep gameplay information visible without covering hazards or the player. Respect safe areas and coordinate CSS behavior with native system-bar configuration.

Use readable text, adequate contrast, redundant state cues (not color alone), configurable audio, subtitles where relevant, reduced-flash/shake options where feasible and clear feedback. Test normal/fullscreen modes, cutouts, aspect ratios, text expansion, rapid taps, pause overlays and low-FPS gameplay.
