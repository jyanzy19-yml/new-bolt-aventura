# Skill: UI/UX and Accessibility for Mobile Games

## Activation
Use for menus, HUD, dialogue, settings, navigation, accessibility and touch ergonomics.

## Interaction model
Every screen defines purpose, primary action, secondary actions, navigation graph, back/cancel behavior, focus/selection, loading/error/empty states and persistence. Avoid dead ends and hidden controls.

## Mobile ergonomics
Design for landscape phones, varied aspect ratios, touch target size/spacing, one- and two-handed reach, thumb occlusion and multitouch. Keep essential gameplay information visible without covering hazards or the player. Respect safe areas and coordinate CSS/system-bar behavior with the native shell.

## Accessibility
Use readable text, adequate contrast, redundant state cues (not color alone), configurable audio, subtitles where relevant, reduced-flash/shake options when feasible, clear feedback and forgiving interaction timing. Avoid motion/visual effects that obscure gameplay.

## QA
Test normal/fullscreen/display modes, safe areas, cutouts, aspect ratios, text scaling, localization expansion, navigation with touch, rapid repeated taps, pause overlays and gameplay under low frame rate. Capture screenshots/video only from actual runs.
