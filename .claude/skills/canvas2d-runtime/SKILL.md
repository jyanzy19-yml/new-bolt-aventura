# Canvas 2D Runtime
Read the master prompt. Use fixed-step simulation, render interpolation when appropriate, monotonic time, clamped deltas and explicit visibility/resume handling. Separate world coordinates from CSS/backing pixels. Bound DPR by measured memory/performance budgets. Implement camera transforms, culling, layers, ordering and resize/orientation behavior. Avoid per-frame allocations, redundant canvas state changes, expensive filters and oversized offscreen surfaces. Keep rendering from mutating simulation. Instrument update/render time, frame time, draw calls and entity counts. Validate DPR, aspect ratios, resize, background resume and large scenes.
