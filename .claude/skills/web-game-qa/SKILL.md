# Web Game QA and Regression
Read the master prompt and relevant skills. Use unit tests for pure logic, integration tests for contracts and browser tests for lifecycle/UI. Control clocks and random seeds; isolate save storage. Cover loop determinism, physics, collisions, Dash, multitouch and pointer cancellation, UI navigation, loading failures, audio lifecycle, save migration, campaign/checkpoints/softlocks and production build. Add regression tests for confirmed defects. Record commands, environment, commit and results. Automated success is not visual or physical-device verification. IMPLEMENTED means code exists; TESTED means specified checks pass; VERIFIED requires representative runtime evidence.
