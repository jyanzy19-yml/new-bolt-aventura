# BOLT · AVENTURA — Catálogo de Skills Ativas

A stack ativa é HTML5, CSS3, JavaScript ES Modules, Canvas 2D e Vite. Comece por `router/SKILL.md`; carregue apenas as especializações necessárias. O conteúdo de skills deve respeitar `MASTER_DIRECTIVE.md`, `AGENTS.md` e as decisões aprovadas.

| Skill | Responsabilidade |
|---|---|
| `html5-game-architecture` | Arquitetura modular, dependências, Vite e lifecycle |
| `canvas2d-runtime` | Renderização Canvas 2D, câmera, frame loop, DPR e lifecycle |
| `canvas-rendering-performance` | Custo de desenho, memória do backing store e frame time |
| `gameplay-physics-loop` | Movimento, colisão, simulação, combate e Dash |
| `deterministic-gameplay-testing` | Relógio determinístico, traces de input e regressões |
| `mobile-input-ux` | Pointer Events, multitouch, safe areas e UX touch |
| `browser-webview-compatibility` | Compatibilidade de browser, WebView e sistema Android |
| `android-web-performance` | Profiling, memória, WebView e comportamento térmico |
| `assets-loading-audio` | Manifestos, loading, decode, cache e Web Audio |
| `asset-provenance-qa` | Licenças, proveniência, aprovação e integridade de assets |
| `web-game-qa` | Testes automatizados/manuais e evidência de regressão |
| `android-capacitor-packaging` | Avaliação do shell Android, Capacitor e APK/AAB |
| `collaborative-development` | Ownership, branches, revisão e handoffs |
| `level-design-content` | Mundos, fases, ritmo, checkpoints e campanha |
| `enemy-boss-design` | Arquétipos, IA, chefes e legibilidade de combate |
| `persistence-save-integrity` | Saves, checkpoints, migração e recuperação |
| `ui-ux-accessibility` | Menus, HUD, ergonomia touch e acessibilidade |
| `web-tooling-ci` | Tooling web, CI, dependências e release gates |

Skills disciplinares engine-neutral (áudio, câmera, diálogo, game feel, UI, IA, level design, física, platformer, saves e criação de assets) podem ser usadas quando compatíveis com a stack HTML5. Skills específicas Godot foram retiradas do catálogo ativo; seu conteúdo permanece recuperável no histórico Git.

Não interpretar a presença de uma skill como prova de implementação ou validação.
