# BOLT · AVENTURA

**Jogo 2D criado do zero em HTML5 para Android.**

A diretriz soberana está em [MASTER_DIRECTIVE.md](MASTER_DIRECTIVE.md). Leia-a antes de planejar, programar ou alterar o projeto.

## Stack
- HTML5, CSS3 e JavaScript ES Modules
- Canvas 2D
- Vite
- Web Audio API
- Pointer Events / multitouch
- Capacitor como opção de empacotamento Android

## Direção
Esta é uma implementação nova, não uma migração. Godot e GDScript não fazem mais parte do projeto. O canon, a narrativa, os sete mundos, sete fragmentos, campanha planejada de 42 fases, personagens, mecânicas, identidade audiovisual e requisitos mobile devem ser preservados conforme o prompt mestre.

## Skills
As skills HTML5 estão em `.claude/skills/`. Comece por `.claude/skills/router/SKILL.md` e carregue somente as especializações necessárias.

## Estado
A redefinição da diretriz e a criação das skills foram registradas. A limpeza integral dos arquivos antigos ainda depende de inventário completo da árvore do repositório; não presuma que a implementação antiga já foi removida.
