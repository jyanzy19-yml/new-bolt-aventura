# Registro de decisões de arquitetura e produto

Registre decisões que afetam canon, escopo, engine, arquitetura, plataformas, dados, performance ou fluxo de produção.

## Índice
- ADR-0001 — Android como plataforma-alvo.
- ADR-0002 — Godot como direção de engine, versão ainda não fixada.
- ADR-0003 — Política imersiva das barras do sistema Android.
- ADR-0004 — Schema mínimo de progresso persistente da campanha.
- ADR-0005 — Fluxo de Nova Jornada e Continuar.\n- ADR-0006 — Extensão da progressão persistente W1-L1 → W1-L2.

## Como usar
1. Criar o próximo número sequencial usando o template em ../templates/decision-record.md.
2. Descrever contexto, opções consideradas, decisão e consequências.
3. Marcar status: proposta, aprovada, rejeitada ou substituída.
4. Só marcar aprovada após confirmação explícita do usuário ou autoridade de projeto.
5. Não reescrever decisão histórica; criar novo ADR para substituição.
